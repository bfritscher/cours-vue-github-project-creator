label: Project Setup
---

As a developer, I want to install the necessary tools for Vue.js development so that I can build and run a Vue application.

### New Concepts

- **Node.js & npm:** The runtime environment and package manager for JavaScript.
- **Git:** The version control system for tracking code changes.
- **Visual Studio Code:** The code editor we will be using.

### Checklist

- [ ] Download and install [Node.js](https://nodejs.org/) to get `npm`.
- [ ] Download and install [Git](https://git-scm.com/download/win) to get `git`.
- [ ] Download and install [Visual Studio Code](https://code.visualstudio.com/) to get `code`.
- [ ] Check that each tool is installed correctly by running the following commands in your shell:

```sh
$ git --version
git version X.Y.Z

$ node --version
vX.Y.Z

$ code --version
X.Y.Z
...
x64
```
