As a developer, I want to install helpful VS Code extensions so that I can have a better development experience with Vue.js.

### New Concepts

- **VS Code Extensions:** Add-ons that provide support for languages, debuggers, and tools.

### Checklist

- [ ] Install the [Vue Official extension](vscode:extension/Vue.volar).
- [ ] Install the [Prettier extension](vscode:extension/esbenp.prettier-vscode) for code formatting.
- [ ] Install the [ESLint extension](vscode:extension/dbaeumer.vscode-eslint) for code quality.
- [ ] Go to `File -> Preferences -> Settings`, search for `vue.autoInsert.dotValue`, and enable it.
