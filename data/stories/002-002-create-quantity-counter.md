As a User, I want to be able to increment and decrement a quantity number with two buttons so that I can easily adjust the quantity of an item.

### New Concepts

- **`ref`:** A function to create a reactive variable.
- **`v-on` or `@`:** A directive to listen for DOM events.

<details>
<summary>Hints</summary>

- [ ] Use the `ref` function to create a reactive variable called `quantity`.
- [ ] Display the current `quantity` value in the template.
- [ ] Add two buttons to increment and decrement the `quantity` value.
- [ ] Use the `v-on` (or `@`) directive to listen for `click` events on the buttons.
- [ ] Use Bootstrap and Font Awesome to make it look nice (e.g., `d-flex`, `align-items-center`, `gap-4`, `fs-3`, `btn`, `btn-secondary`, `btn-sm`).
</details>
