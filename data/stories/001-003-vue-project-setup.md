As a developer, I want to create a new Vue.js project so that I can start building my application.

### New Concepts

- **Vue CLI:** The command-line interface for creating and managing Vue projects.

### Checklist

- [ ] Change to a parent folder where the project folder will be created.
- [ ] Use the Vue CLI to create a new project:
  ```sh
  C:\\temp> npm create vue@latest
  ```
- [ ] When prompted, use the following settings:
  - Project name: `labo-vue`
  - Select features: `ESLint` and `Prettier`
  - No experimental features
  - Skip all example code and start with a blank Vue project? `Yes`
